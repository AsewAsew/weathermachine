Hate the sound of rain in Minecraft? Hate waiting for thunder storms for your  Wither Skeleton farm? Then this is the mod for you!

## Weather Machine
Controling the weather has never been easier! Change the weather between clear, rain, and thunder with a simple click. It still follows standard Minecraft weather patterns (snows in cold biomes, none in hot). By default, it changes the weather for 10 minutes and has 32 durability with unbreaking and mending to enhance it. There is a 5 second cooldown between uses, but that's only to allow the weather to _actually_ change. Also, to help not waste durability, it does prevent you from using it if the weather matches the current mode.

## Modes
Change between modes by Shift-Right Clicking. Standard Minecraft weather.
- Clear
- Rain
- Thunder

### ***NOTICE***
If you use it to set the weather to clear, it will start to thunder as soon as the as the timer clears.
